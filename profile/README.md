## KeroKero

**Sistemas de decisión para tu operación.**

Conectamos el ERP, el CRM y los Excel de una empresa con el criterio de su equipo, para que sepa qué comprar, a quién atender o dónde intervenir primero. Trabajamos con equipos de Operaciones, Compras y TI en Chile, Argentina y Perú.

### Código abierto

**[mercadopublico](https://github.com/keroke-ro/mercadopublico)**: SDK, CLI y servidor MCP en TypeScript para la API de Mercado Público de ChileCompra. Junta la API v1, Compra Ágil y las descargas OCDS en un solo modelo, cuida la cuota diaria del ticket y no tiene dependencias en runtime. Se puede usar desde código, desde la terminal o desde Claude.

```sh
npx mercadopublico
```

[Repositorio](https://github.com/keroke-ro/mercadopublico) · [npm](https://www.npmjs.com/package/mercadopublico) · [Por qué lo hicimos](https://www.kerokero.cl/mercadopublico)
